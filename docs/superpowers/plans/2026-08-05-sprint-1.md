# Sprint 1 Implementation Plan — Foundation, Auth, Vehicle Registry

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the monorepo, the 16-table MySQL schema with a seeded synthetic Belagavi, M01 User & Access Management, M03 Vehicle Management, the cache/jobs/bus adapter shells, and a React app shell with working Sign-in and Fleet screens.

**Architecture:** npm-workspaces monorepo. `apps/api` is an Express 4 service — the only writer to MySQL — layered as routes → controller → service → model, with zod parsing at every route boundary. `apps/web` is a React 18 SPA where MUI owns components and Tailwind owns layout, both reading colour from one `tokens.css`. `packages/shared-types` carries the DTOs and envelopes both sides agree on. Cache, job queue and event bus sit behind driver interfaces so Redis is a later one-file swap.

**Tech Stack:** Node 22.23.1 (native TypeScript type stripping — no `tsx`/`ts-node`/`nodemon`), Express 4, Sequelize 6 + `mysql2`, umzug, zod, MySQL 8.4.10, React 18, Vite, MUI v5 + `@mui/x-data-grid`, Tailwind 3.4, TanStack Query, Zustand, Vitest + Supertest.

**Spec:** `docs/superpowers/specs/2026-08-05-sprint-1-design.md`. Read it before Task 1. Where this plan and the spec disagree, the spec wins — stop and flag it.

## Global Constraints

Every task's requirements implicitly include this section.

- **Node 22.23.1, npm 10.9.8, Python 3.13.11, MySQL 8.4.10, all local. No Docker. No Redis.**
- **Never add** `redis`, `ioredis`, `bullmq`, `dotenv`, `nodemon`, `node-fetch`, `axios`, `moment`, `mongoose`, `prisma`, or a second chart library. Node 22 provides `--env-file`, `--watch`, `fetch`, `structuredClone`.
- **ESM everywhere.** Every `package.json` sets `"type": "module"`. Every relative import writes the **explicit `.ts` extension** (`import { x } from './foo.ts'`) — required by Node's type stripping and by `nodenext` resolution.
- **`erasableSyntaxOnly: true`** in every tsconfig. No TS `enum`, no `namespace`, no parameter properties, no decorators — type stripping cannot erase them. Use `const` objects with `as const` plus a union type instead.
- **Sequelize must use `mysql2`.** `dialectOptions: { allowPublicKeyRetrieval: true }` for localhost only — MySQL 8.4 removed `mysql_native_password`.
- **`DECIMAL` arrives from `mysql2` as a string.** Convert in the DTO mapper, never deeper.
- **Geometry only through `db/spatial.ts`.** No other file may call `ST_GeomFromText`, `ST_AsText`, or any `ST_*` function. Coordinates are `[lng, lat]` in application code, always.
- **Migrations are immutable once committed.** Fix forward with a new migration.
- **No raw SQL in controllers.** Service layer only, parameterized.
- **No hex colour literal in any React component.** Colour comes from `tokens.css` via Tailwind classes or the MUI theme.
- **Envelopes:** success `{ "data": ..., "meta": {...} }`, error `{ "error": { "code", "message", "details" } }`. `code` is stable SCREAMING_SNAKE.
- **API base path `/api/v1`.** Cursor pagination for feeds, offset for admin tables.
- **Tests target `micromobility_test` only.** The truncate helper must assert the schema name ends in `_test` — this MySQL instance hosts 15 unrelated project databases.
- **Timestamps** `DATETIME(3)`, UTC, converted at the edge. Tables `snake_case` plural; models `PascalCase` singular.
- **Commit at the end of every task** with a module-scoped message.

```ts
function required(name: string): string {
  const v = process.env[name];
  if (v === undefined || v === '') throw new Error(`Missing required env var: ${name}`);

function optional(name: string, fallback: string): string {
  const v = process.env[name];
```

```ts
import type { ApiErrorDetail, ErrorCode } from '@mm/shared-types';

export const STATUS_BY_CODE: Record<ErrorCode, number> = {
  VALIDATION_FAILED: 400,
  UNAUTHENTICATED: 401,
  INVALID_CREDENTIALS: 401,
  TOKEN_EXPIRED: 401,
  REFRESH_TOKEN_INVALID: 401,
  REFRESH_TOKEN_REUSED: 401,
  FORBIDDEN: 403,
  USER_NOT_FOUND: 404,
  VEHICLE_NOT_FOUND: 404,
  MAINTENANCE_TICKET_NOT_FOUND: 404,
  SAVED_PLACE_NOT_FOUND: 404,
  EMAIL_ALREADY_REGISTERED: 409,
  VEHICLE_REF_ALREADY_EXISTS: 409,
  INVALID_STATE_TRANSITION: 409,
  RATE_LIMITED: 429,
  INTERNAL_ERROR: 500,
};

export class AppError extends Error {
  readonly code: ErrorCode;
  readonly status: number;
  readonly details?: ApiErrorDetail[];

  constructor(code: ErrorCode, message: string, details?: ApiErrorDetail[]) {
    super(message);
    this.name = 'AppError';
    this.code = code;
    this.status = STATUS_BY_CODE[code];
    this.details = details;
  }

  static unauthenticated(message = 'Authentication required') {
    return new AppError('UNAUTHENTICATED', message);
  }
  static forbidden(message = 'You do not have access to this resource') {
    return new AppError('FORBIDDEN', message);
  }
  static notFound(code: ErrorCode, message: string) {
    return new AppError(code, message);
  }
  static conflict(code: ErrorCode, message: string) {
    return new AppError(code, message);
  }
  static validationFailed(details: ApiErrorDetail[]) {
    return new AppError('VALIDATION_FAILED', 'Request validation failed', details);
  }
}
```

```ts
import type { ApiError, ApiErrorDetail, ApiMeta, ApiSuccess, ErrorCode } from '@mm/shared-types';

export function ok<T>(data: T, meta?: ApiMeta): ApiSuccess<T> {
  return meta === undefined ? { data } : { data, meta };
}

export function fail(code: ErrorCode, message: string, details?: ApiErrorDetail[]): ApiError {
  return { error: details === undefined ? { code, message } : { code, message, details } };
}
```

```ts
import { Sequelize } from 'sequelize';
import type { Literal } from 'sequelize/lib/utils';
import type { GeoLineString, GeoPoint, GeoPolygon, LngLat } from '@mm/shared-types';

const SRID = 4326;
const AXIS = "'axis-order=long-lat'";

/**
 * MySQL 8 treats SRID 4326 as latitude-longitude. GeoJSON, MapLibre and deck.gl
 * all use longitude-latitude. Every read and write in this project passes
 * axis-order=long-lat so application code can speak [lng, lat] everywhere.
 * This file is the ONLY place an ST_* function may appear.
 */
function escapeNum(n: number): string {
  if (!Number.isFinite(n)) throw new Error(`Non-finite coordinate: ${n}`);
  return String(n);
}
const pair = ([lng, lat]: LngLat) => `${escapeNum(lng)} ${escapeNum(lat)}`;

export function pointLiteral(p: LngLat): Literal {
  return Sequelize.literal(`ST_GeomFromText('POINT(${pair(p)})', ${SRID}, ${AXIS})`);
}

export function lineStringLiteral(coords: LngLat[]): Literal {
  if (coords.length < 2) throw new Error('LINESTRING needs at least 2 coordinates');
  return Sequelize.literal(
    `ST_GeomFromText('LINESTRING(${coords.map(pair).join(',')})', ${SRID}, ${AXIS})`,
  );
}

export function polygonLiteral(ring: LngLat[]): Literal {
  if (ring.length < 3) throw new Error('POLYGON ring needs at least 3 coordinates');
  const first = ring[0]!;
  const last = ring[ring.length - 1]!;
  const closed = first[0] === last[0] && first[1] === last[1] ? ring : [...ring, first];
  return Sequelize.literal(
    `ST_GeomFromText('POLYGON((${closed.map(pair).join(',')}))', ${SRID}, ${AXIS})`,
  );
}

/** SELECT fragment: `ST_AsText(col, 'axis-order=long-lat') AS alias` */
export function selectGeom(col: string, alias: string): string {
  return `ST_AsText(${col}, ${AXIS}) AS ${alias}`;
}

function coords(body: string): LngLat[] {
  return body.split(',').map((p) => {
    const [lng, lat] = p.trim().split(/\s+/).map(Number);
    if (lng === undefined || lat === undefined || Number.isNaN(lng) || Number.isNaN(lat)) {
      throw new Error(`Unparseable coordinate pair: "${p}"`);
    }
    return [lng, lat] as LngLat;
  });
}

export function parsePoint(wkt: string | null): GeoPoint | null {
  if (!wkt) return null;
  const m = /^POINT\((.+)\)$/.exec(wkt.trim());
  if (!m?.[1]) throw new Error(`Not a POINT: ${wkt}`);
  return { type: 'Point', coordinates: coords(m[1])[0]! };
}

export function parseLineString(wkt: string | null): GeoLineString | null {
  if (!wkt) return null;
  const m = /^LINESTRING\((.+)\)$/.exec(wkt.trim());
  if (!m?.[1]) throw new Error(`Not a LINESTRING: ${wkt}`);
  return { type: 'LineString', coordinates: coords(m[1]) };
}

export function parsePolygon(wkt: string | null): GeoPolygon | null {
  if (!wkt) return null;
  const m = /^POLYGON\(\((.+)\)\)$/.exec(wkt.trim());
  if (!m?.[1]) throw new Error(`Not a POLYGON: ${wkt}`);
  return { type: 'Polygon', coordinates: [coords(m[1])] };
}
```

```ts
/**
 * Union-find over segment endpoints. A disconnected road graph would silently
 * break A* in Sprint 3, and the failure would look like a routing bug rather
 * than a data bug — so the seed refuses to insert one.
 */
export function assertConnected(edges: Array<[string, string]>): void {
  if (edges.length === 0) throw new Error('Road graph has no edges');

  const parent = new Map<string, string>();
  const find = (x: string): string => {
    let root = parent.get(x) ?? x;
    if (root !== x) { root = find(root); parent.set(x, root); }
    return root;
  };
  const union = (a: string, b: string) => {
    const ra = find(a); const rb = find(b);
    if (ra !== rb) parent.set(ra, rb);
  };

  for (const [a, b] of edges) {
    if (!parent.has(a)) parent.set(a, a);
    if (!parent.has(b)) parent.set(b, b);
    union(a, b);
  }

  const roots = new Set([...parent.keys()].map(find));
  if (roots.size !== 1) {
    throw new Error(
      `Road graph is not connected: ${roots.size} components across ${parent.size} nodes`,
    );
  }
}
```

```ts
// src/cache/index.ts
import { env } from '../config/env.ts';
import { MemoryCacheDriver } from './drivers/memory.ts';

export interface CacheDriver {
  get<T>(key: string): Promise<T | undefined>;
  set<T>(key: string, value: T, ttlSeconds: number): Promise<void>;
  del(key: string): Promise<void>;
  wrap<T>(key: string, ttlSeconds: number, producer: () => Promise<T>): Promise<T>;
}

function build(): CacheDriver {
  switch (env.cacheDriver) {
    case 'memory': return new MemoryCacheDriver();
    default:
      throw new Error(
        `Unknown CACHE_DRIVER "${env.cacheDriver}". Only "memory" exists; Redis is a later sprint.`,
      );
  }
}

export const cache: CacheDriver = build();
```

```ts
import type { NextFunction, Request, Response } from 'express';
import type { ZodTypeAny } from 'zod';
import { AppError } from '../lib/errors.ts';

export interface ValidSchemas { body?: ZodTypeAny; query?: ZodTypeAny; params?: ZodTypeAny }

declare module 'express-serve-static-core' {
  interface Request {
    valid?: { body?: unknown; query?: unknown; params?: unknown };
    user?: { id: string; email: string; roles: string[]; operatorId: string | null };
    apiKey?: { id: string; scopes: string[]; operatorId: string | null };
  }
}

export function validate(schemas: ValidSchemas) {
  return (req: Request, _res: Response, next: NextFunction) => {
    const valid: Record<string, unknown> = {};
    for (const part of ['body', 'query', 'params'] as const) {
      const schema = schemas[part];
      if (!schema) continue;
      const result = schema.safeParse(req[part]);
      if (!result.success) {
        return next(
          AppError.validationFailed(
            result.error.issues.map((i) => ({ path: i.path.join('.'), message: i.message })),
          ),
        );
      }
      valid[part] = result.data;
    }
    req.valid = valid;
    next();
  };
}
```

```ts
import type { VehicleStatus } from '@mm/shared-types';
import { AppError } from '../../lib/errors.ts';

/**
 * MODULES.md M03 writes the states as a chain; that is a reading order, not the
 * transition graph. Spec §5 is the contract:
 *  - reserved is optional (scan-and-go goes straight to in_use)
 *  - maintenance/charging are reachable from any live state (breakdowns happen mid-ride)
 *  - retired is terminal, so it stays a trustworthy filter. Refurbishment registers
 *    a new vehicle rather than resurrecting a retired one.
 * Self-transitions are rejected, not treated as no-ops, so a duplicated request
 * cannot write a spurious vehicle_status_history row.
 */
export const TRANSITIONS: Readonly<Record<VehicleStatus, readonly VehicleStatus[]>> = Object.freeze({
  available:   Object.freeze(['reserved', 'in_use', 'charging', 'maintenance', 'retired'] as const),
  reserved:    Object.freeze(['in_use', 'available', 'maintenance'] as const),
  in_use:      Object.freeze(['returning', 'maintenance'] as const),
  returning:   Object.freeze(['available', 'charging', 'maintenance'] as const),
  charging:    Object.freeze(['available', 'maintenance', 'retired'] as const),
  maintenance: Object.freeze(['available', 'charging', 'retired'] as const),
  retired:     Object.freeze([] as const),
});

export function canTransition(from: VehicleStatus, to: VehicleStatus): boolean {
  return TRANSITIONS[from].includes(to);
}

export function assertTransition(from: VehicleStatus, to: VehicleStatus): void {
  if (!canTransition(from, to)) {
    throw new AppError(
      'INVALID_STATE_TRANSITION',
      `Cannot move a vehicle from "${from}" to "${to}". Allowed from "${from}": ` +

}
```
